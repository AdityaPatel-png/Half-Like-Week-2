My week 2 project will be a chess set that is 3d printed, except the pawns will be able to transform into other pieces when promoting.
I intend to create a pen click style mechanism, using springs and 3D printed parts, to make the pawn spring into shape.
Because of their transformation, the only pieces required to fill the board will be the king and a few of each type of pawn.
The pieces will also be magnetized to stick to the board and possibly also be used inside the board to make storage easier.
